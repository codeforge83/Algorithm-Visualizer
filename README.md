# ⚡ Algo Lab

> **An interactive algorithm visualization platform designed to make Data Structures & Algorithms easier to understand, explore, and master.**

Algo Lab provides an interactive way to visualize algorithms **step by step**, helping learners understand how algorithms work rather than simply reading their implementations.

## ✨ Features

- 🎨 **Interactive Visualizations** — Learn algorithms through dynamic visual representations.
- ▶️ **Step-by-Step Execution** — Follow the execution of an algorithm one operation at a time.
- 📊 **Sorting Visualization** — Visualize sorting algorithms and understand their behavior.
- 🔍 **Searching Visualization** — Explore searching algorithms interactively.
- 🌳 **Tree Traversal** — Visualize BFS and DFS traversals on trees.
- 🕸️ **Graph Traversal** — Visualize BFS and DFS traversals on graphs.
- 🎮 **Interactive Controls** — Play, pause, and reset algorithm execution.
- ⌨️ **Custom Input** — Provide your own input for supported algorithms.
- 📱 **Responsive Interface** — Designed to work across different screen sizes.
- 💡 **Learning-Oriented Design** — Connect algorithmic concepts with their visual execution.

# 🚀 Getting Started

Follow these steps to run Algo Lab locally.

### 1. Clone the Repository

    git clone https://github.com/codeforge83/Algorithm-Visualizer.git

### 2. Navigate to the Project Directory

    cd Algorithm-Visualizer

If your project contains a separate frontend directory:

    cd frontend

### 3. Install Dependencies

    npm install

### 4. Start the Development Server

    npm run dev

The application will usually be available at:

    http://localhost:5173

Open the URL in your browser to start using **Algo Lab**.
